## 2. 判定为不可行 / 高成本的路线（附证据）

### 2.1 协议层（明文）

| 项 | 结论 |
|---|---|
| 游戏服 | `42.186.128.28:10002`，自定义帧，**无明文头、非 TLS** |
| SDK 登录 | `117.147.201.71:443`，标准 TLS 1.2 |
| `libtcb.so` | **是 Houdini 的 CPU 特性表/桥接层**，不是游戏网络库 |
| `EVP_*` hook | 20 s 内 **0 次调用** → 加密不走 OpenSSL EVP |
| 实际加密实现 | 静态编译进 `libGame.so` 的 **ARM 代码**（OpenSSL 有 442 条源码路径字符串） |
| 游戏 socket 的 recv | **不经过 libc 导出**（走 Houdini syscall 桥）→ hook 不到 |
| 静态反汇编 | 磁盘文件代码段**加密**，只有内存镜像才是明文（已 dump 77 MB） |

→ 要出明文需要逆 ARM 代码，**3–7 天量级**。

### 2.2 "纯内存拿控件坐标"

耗尽式搜索，**全部落空**：

| 搜索 | 覆盖 | 结果 |
|---|---|---|
| `float(757,425)` / `int32(757,425)` | scudo 750 MB + anon 160 MB | ❌ |
| 矩形四元组 `(685,405,835,445)` | 同上 | ❌ |
| 设计分辨率缩放 ×4/3、×1.5、×2、1136×640 | 同上 | ❌ |
| 顶点缓冲扫描 | scudo | 无有效命中 |

**为什么**：控件描述符里只有
```
size (150,50) | anchor (0.5,0) | 变换矩阵（单位阵）
```
**没有位置** —— 位置是绘制时沿父链累乘算出来的，而对象之间**没有任何父子指针**（9,112 个对象里 0 个互指）。

另外确认：**主 UI 不是 Cocos2d-x 节点树**。虽然镜像里有 886 个 `N7cocos2d*` RTTI 名、`Cocos2dxPrefsFile.xml` 也在实时写入，但那 9,112 个 vtable 对象：

- **没有 `_name` 字段**（Cocos Node 必有）
- **没有父子链**
- 容器指针对全是空

→ 它们是渲染层 sprite，不是控件树。
